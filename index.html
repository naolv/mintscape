1. Was ist der micro:bit?

Der BBC micro:bit ist ein winziger Computer auf einer Platine. Mit Python schreibst du Befehle, die der micro:bit direkt ausführt.

🔍 Hardware-Detektiv: Suchst du die Teile auf deinem micro:bit?

Nimm deinen echten micro:bit in die Hand! Klicke unten auf ein Bauteil und schau, ob du es auf deiner Platine entdeckst:

Klicke oben auf einen Knopf, um zu erfahren, wo du das Bauteil auf deinem echten micro:bit findest!

🧩 Aufgabe: Das blinkende Herz

Schreibe deinen ersten eigenen Code in den Editor auf der rechten Seite!

from microbit import * while True: display.show(Image.HEART) sleep(500) display.clear() sleep(500)
🌟 Herausforderung: Ändere das Bild! Lass erst ein fröhliches Gesicht (HAPPY) anzeigen und danach ein trauriges (SAD). Verändere auch die Pausenzeiten mit sleep()!

2. Projekt: Der Schrittzähler 🏃

Das Prinzip der Variablen:
Eine Variable ist wie eine beschriftete Box im Speicher. In schritte speichern wir ab, wie oft der Bewegungssensor Erschütterungen misst.

💻 Code für deinen Schrittzähler

Programmiere deine eigene Schrittzähler-Logik:

from microbit import * schritte = 0 while True: display.show(schritte) if accelerometer.was_gesture('shake'): schritte = schritte + 1 sleep(200) if button_a.is_pressed(): schritte = 0
✂️ Real-Life Bastelauftrag: Baue ein Trageband!
  1. Schliesse das externe Batteriepack an deinen micro:bit an.
  2. Schneide aus Karton einen Streifen (ca. 4 × 12 cm) aus.
  3. Befestige den micro:bit mit Gummibändern oder einer Büroklammer am Karton.
  4. Klemme den Schrittzähler an deinen Schuh oder Hosenbund und mache 10 Schritte im Schulzimmer. Funktioniert dein Zähler?
🌟 Zusatz-Code: Lass den micro:bit ein Stern-Symbol (Image.STAR) anzeigen, sobald du mehr als 10 Schritte geschafft hast!

3. Projekt: Türsensor 🚪

Bedingungen verstehen (Wenn ... Dann ... Sonst):
Der Kompass-Sensor misst Magnetfelder. Ein Magnet an der Tür hält den Wert hoch. Wird die Tür geöffnet, fällt die Stärke ab und der micro:bit schlägt Alarm!

💻 Code für die Alarmanlage

from microbit import * while True: magnet = compass.get_field_strength() if magnet > 50000: display.show(Image.YES) else: display.show(Image.SKULL) sleep(100) display.clear() sleep(100)
📚 Befehlssammlung / Spickzettel (Hier nachschlagen!)
display.show(Image.NAME)
Zeigt ein Bild auf den LEDs an. (Mögliche Namen: HEART, HAPPY, SAD, YES, NO, SKULL, PACMAN, STAR).
display.show(variable_oder_zahl)
Zeigt eine Zahl oder eine Variable (z.B. den Schrittzähler) auf dem LED-Raster an.
display.clear()
Löscht alle LEDs (Bildschirm wird dunkel).
sleep(zeit_in_ms)
Wartet eine bestimmte Zeit in Millisekunden (1000 ms = 1 Sekunde).
accelerometer.was_gesture('shake')
Prüft, ob der micro:bit geschüttelt wurde.
button_a.is_pressed()
Prüft, ob der Knopf A gerade gedrückt wird.
compass.get_field_strength()
Misst die Stärke des Magnetfelds in der Umgebung.
⚙️ Wichtig: WebTigerPython richtig einstellen (hier klicken)
Damit WebTigerPython den micro:bit versteht, mache Folgendes im Editor:
  1. Klicke ganz oben rechts auf die drei Punkte ⋮ (Menü).
  2. Klicke auf den Menüpunkt «Gerät».
  3. Wähle in der Liste «micro:bit» aus.
(Verhindert die Fehlermeldung «No module named microbit»!)
