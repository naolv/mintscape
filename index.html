1. Was ist der micro:bit?

Der BBC micro:bit ist ein kleiner, programmierbarer Computer. Mit Python-Befehlen sagst du ihm genau, was er tun soll!

Nimm deinen echten micro:bit in die Hand und suche die Teile auf der Platine:

Klicke oben auf einen Knopf, um zu erfahren, wo du das Bauteil auf deinem echten micro:bit findest!

2. Projekt: Der Schrittzähler 🏃

Das Prinzip der Variablen:
Eine Variable ist wie eine kleine Merk-Box im Speicher. In schritte zählen wir jedes Mal +1, wenn der Bewegungssensor geschüttelt wird.

💻 Bauplan: Schrittzähler programmieren

Lies die Kommentare mit # aufmerksam durch. Ersetze die gelben Lücken durch die richtigen Befehle!

from microbit import * # Wir starten mit 0 Schritten in der Speicher-Box schritte = 0 while True: # Zeige die Zahl an, die in der Variable steckt: [BEFEHL: ZEIGE DIE VARIABLE 'schritte'] # WENN der micro:bit geschüttelt wurde: if accelerometer.was_gesture('shake'): # Erhöhe den Zähler um 1 schritte = schritte + 1 sleep(200) # WENN Knopf A gedrückt wird (Reset): if button_a.is_pressed(): # Setze den Zähler wieder auf 0 zurück schritte = [WELCHE ZAHL KOMMT HIER HIN?]
✂️ Real-Life Bastelauftrag: Baue ein Trageband!
  1. Schliesse das Batteriepack an deinen micro:bit an.
  2. Schneide aus Karton einen Streifen (ca. 4 × 12 cm) aus.
  3. Befestige den micro:bit mit Gummibändern oder einer Büroklammer am Karton.
  4. Klemme den Schrittzähler an deinen Schuh oder Hosenbund und mache 10 Schritte im Schulzimmer. Rechnet dein Zähler richtig?

3. Projekt: Türsensor 🚪

Bedingungen verstehen (Wenn ... Dann ... Sonst):
Der Magnet-Sensor misst unsichtbare Magnetfelder. Ist ein Magnet an der Tür nahe bei deinem micro:bit, ist der Wert hoch (> 50000). Geht die Tür auf, fällt der Wert ab!

💻 Bauplan: Alarmanlage tüfteln

from microbit import * while True: # Stärke des Magnetfelds messen magnet = compass.get_field_strength() # WENN der Magnet nah ist (Tür ZU): if magnet > 50000: display.show(Image.YES) # SONST (Magnet weg = Tür AUF = ALARM!): else: # Zeige einen Totenkopf oder ein Warnzeichen an: [DEIN BILD-BEFEHL] sleep(100) display.clear() sleep(100)
📚 Befehlssammlung / Spickzettel (Hier Befehle nachschlagen!)
display.show(Image.NAME)
Zeigt ein vordefiniertes Bild an. (Auswahl: HEART, HAPPY, SAD, YES, NO, SKULL, PACMAN, STAR).
display.show(variable_oder_zahl)
Zeigt eine Zahl oder den Inhalt einer Variable (z.B. schritte) an.
display.clear()
Löscht alle Lämpchen auf dem Display.
sleep(zeit_in_ms)
Pausiert den micro:bit für eine Zeit in Millisekunden (1000 ms = 1 Sekunde).
accelerometer.was_gesture('shake')
Erkennt, wenn der micro:bit geschüttelt wurde.
button_a.is_pressed()
Prüft, ob der Knopf A gerade gedrückt wird.
compass.get_field_strength()
Misst die Magnetfeldstärke der Umgebung.
