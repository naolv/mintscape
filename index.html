2. Projekt: Der intelligente Schrittzähler 🏃

Wie funktioniert das? Der micro:bit hat einen integrierten Beschleunigungssensor (Accelerometer). Wenn du dich bewegst oder den Board schüttelst, erkennt er das und zählt eine Variable (Schritte) hoch!

So funktioniert der Code:

  1. schritte = 0: Wir erstellen ein Gedächtnis (Variable) für die Schritte.
  2. accelerometer.was_gesture('shake'): Prüft, ob der micro:bit geschüttelt wurde.
  3. schritte += 1: Erhöht den Zähler um 1.
  4. button_a.is_pressed(): Bei Druck auf Knopf A wird der Zähler wieder auf 0 zurückgesetzt.

Code zum Kopieren:

from microbit import * schritte = 0 while True: # Zeige die aktuelle Schrittzahl an display.show(schritte) # Wenn geschüttelt wird: Schritt hinzufügen if accelerometer.was_gesture('shake'): schritte = schritte + 1 sleep(200) # Reset mit Knopf A if button_a.is_pressed(): schritte = 0 display.show(Image.NO) sleep(500)

3. Projekt: Türsensor & Alarmanlage 🚪

Wie funktioniert das? Auf dem micro:bit ist ein Kompass verbaut, der auch als Magnet-Sensor dient. Wenn du einen kleinen Küchenmagneten an den Türrahmen klebst und den micro:bit an die Tür hängst, erkennt er sofort, wenn die Tür geöffnet wird!

So funktioniert der Code:

  1. compass.get_field_strength(): Misst die Stärke des Magnetfelds in der Nähe.
  2. Wenn der Magnet nah ist (Tür zu): Zeige ein Häkchen.
  3. Wenn der Magnet entfernt wird (Tür auf): Zeige ein Totenkopf-Symbol und spiele einen Alarmton!

Code zum Kopieren:

from microbit import * while True: # Stärke des Magnetfelds messen magnet_staerke = compass.get_field_strength() # Ist der Magnet nah? (Wert anpassen falls nötig) if magnet_staerke > 100000: display.show(Image.YES) # Tür ist ZU else: display.show(Image.SKULL) # ALARM: Tür ist OFFEN! sleep(200) display.clear() sleep(200)
