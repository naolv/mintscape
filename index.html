1. Was ist der micro:bit?

Der BBC micro:bit ist ein kleiner, programmierbarer Computer. Mit Python-Befehlen sagst du ihm genau, was er tun soll!

Hardware-Detektiv: Wo sind die Bauteile?

Nimm deinen echten micro:bit in die Hand und suche die Teile auf der Platine:

Klicke oben auf einen Knopf, um zu erfahren, wo du das Bauteil auf deinem echten micro:bit findest!

Aufgabe: Das blinkende Herz programmieren

Schau unten in die Befehlssammlung, suche die richtigen Befehle und tippe den Code im Editor rechts selbst zusammen:

# 1. Wir holen alle micro:bit Befehle from microbit import * # 2. Endlosschleife: Wiederhole alles ewig while True: # Zeige ein Herz auf den LEDs an: [HIER BEFEHL FÜR HEART EINSETZEN] # Warte 500 Millisekunden (1/2 Sekunde): sleep(500) # Lösche den Bildschirm wieder: [HIER BEFEHL ZUM BILDSCHIRM LÖSCHEN EINSETZEN] # Warte nochmals 500 Millisekunden: sleep(500)
Tüftel-Auftrag: Ändere dein Programm so, dass abwechselnd ein fröhliches Gesicht (HAPPY) und ein trauriges Gesicht (SAD) aufblitzt!

2. Projekt: Der Schrittzähler

Das Prinzip der Variablen:
Eine Variable ist wie eine kleine Merk-Box im Speicher. In schritte zählen wir jedes Mal +1, wenn der Bewegungssensor geschüttelt wird.

Bauplan: Schrittzähler programmieren

Lies die Kommentare mit # aufmerksam durch. Ersetze die gelben Lücken durch die richtigen Befehle!

from microbit import * # Wir starten mit 0 Schritten in der Speicher-Box schritte = 0 while True: # Zeige die Zahl an, die in der Variable steckt: [BEFEHL: ZEIGE DIE VARIABLE 'schritte'] # WENN der micro:bit geschüttelt wurde: if accelerometer.was_gesture('shake'): # Erhöhe den Zähler um 1 schritte = schritte + 1 sleep(200) # WENN Knopf A gedrückt wird (Reset): if button_a.is_pressed(): # Setze den Zähler wieder auf 0 zurück schritte = [WELCHE ZAHL KOMMT HIER HIN?]
Real-Life Bastelauftrag: Baue ein Trageband!
  1. Schliesse das Batteriepack an deinen micro:bit an.
  2. Schneide aus Karton einen Streifen (ca. 4 × 12 cm) aus.
  3. Befestige den micro:bit mit Gummibändern oder einer Büroklammer am Karton.
  4. Klemme den Schrittzähler an deinen Schuh oder Hosenbund und mache 10 Schritte im Schulzimmer. Rechnet dein Zähler richtig?
Tüftel-Auftrag: Bau eine Ziel-Belohnung ein! Wenn schritte > 10 sind, soll ein Stern (Image.STAR) auf den LEDs leuchten.

3. Projekt: Türsensor

Bedingungen verstehen (Wenn ... Dann ... Sonst):
Der Magnet-Sensor misst unsichtbare Magnetfelder. Ist ein Magnet an der Tür nahe bei deinem micro:bit, ist der Wert hoch (> 50000). Geht die Tür auf, fällt der Wert ab!

Bauplan: Alarmanlage tüfteln

from microbit import * while True: # Stärke des Magnetfelds messen magnet = compass.get_field_strength() # WENN der Magnet nah ist (Tür ZU): if magnet > 50000: display.show(Image.YES) # SONST (Magnet weg = Tür AUF = ALARM!): else: # Zeige einen Totenkopf oder ein Warnzeichen an: [DEIN BILD-BEFEHL] sleep(100) display.clear() sleep(100)
Real-Life Bastelauftrag: Sichere das Schulzimmer!
  1. Befestige einen kleinen Magneten mit Klebeband am Türrahmen.
  2. Kleb deinen micro:bit (mit Batteriepack) direkt gegenüber an das Türblatt. Bei geschlossener Tür sollten sie fast aneinanderstossen.
  3. Schliesse die Tür und starte dein Programm.
  4. Öffne die Tür langsam: Verwandelt sich das Häkchen (YES) sofort in einen Alarm (SKULL)?
Tüftel-Auftrag: Ändere den Grenzwert (50000) im Code, wenn deine Tür auch bei geschlossener Tür schon Alarm schlägt!

4. Projekt: Das digitale Thermometer

Messdaten verarbeiten:
Der Prozessor des micro:bit kann die Umgebungstemperatur in Grad Celsius messen. Mit Bedingungen vergleicht der micro:bit, ob es zu kalt, genau richtig oder zu heiss ist.

Bauplan: Wetterstation programmieren

from microbit import * while True: # Temperatur im Schulzimmer messen grad = temperature() # WENN Taste A gedrückt wird: Zeige genaue Gradzahl if button_a.is_pressed(): display.scroll(grad) # WENN die Temperatur unter 20 Grad ist (zu kalt): if grad < 20: display.show(Image.SAD) # WENN die Temperatur 20 Grad oder mehr ist (angenehm): else: [BEFEHL FÜR EIN FRÖHLICHES GESICHT EINSETZEN]
Real-Life Bastelauftrag: Die Pflanzen-Wetterstation!
  1. Schneide aus Karton ein kleines Schild (Form einer Blume oder einer Wolke) aus.
  2. Befestige ein Holzstäbchen (z.B. Eisstiel oder Bleistift) als Ständer am Karton.
  3. Binde den micro:bit mit Gummibändern an den Karton und stecke deine Wetterstation in eine Topfpflanze beim Fenster.
  4. Messe die Temperatur am Fenster und vergleiche sie mit der Temperatur bei deinem Pult!
Tüftel-Auftrag: Reibe deine Hände aneinander, halte den Fingernagel auf die Rückseite des micro:bit-Chips und drücke Taste A. Steigt die Temperatur an?
Befehlssammlung / Spickzettel (Hier Befehle nachschlagen!)
display.show(Image.NAME)
Zeigt ein vordefiniertes Bild an. (Auswahl: HEART, HAPPY, SAD, YES, NO, SKULL, PACMAN, STAR).
display.show(variable_oder_zahl)
Zeigt eine Zahl oder den Inhalt einer Variable (z.B. schritte) an.
display.scroll(variable_oder_zahl)
Lässt längere Zahlen oder Wörte als Laufschrift über den Bildschirm wandern.
display.clear()
Löscht alle Lämpchen auf dem Display.
sleep(zeit_in_ms)
Pausiert den micro:bit für eine Zeit in Millisekunden (1000 ms = 1 Sekunde).
accelerometer.was_gesture('shake')
Erkennt, wenn der micro:bit geschüttelt wurde.
button_a.is_pressed()
Prüft, ob der Knopf A gerade gedrückt wird.
compass.get_field_strength()
Misst die Magnetfeldstärke der Umgebung.
temperature()
Misst die Temperatur des Prozessors in Grad Celsius.
