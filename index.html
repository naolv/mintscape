1. Was ist der micro:bit?

Der BBC micro:bit ist ein winziger Einplatinen-Computer. Trotz seiner kleinen Größe steckt er voller Technik: Er besitzt ein Display aus 25 roten Lichterketten (LEDs), Tasten, Sensoren für Bewegung und Temperatur sowie ein Mikrofon. Mit Python schreibst du Befehle, die der micro:bit direkt ausführt.

🔍 Entdecke die Hardware (Klicke zum Erkunden):

Klicke oben auf ein Bauteil, um zu sehen, was es kann!

🧩 Aufgabe: Das blinkende Herz

Tippe den folgenden Code rechts in den Editor ein. Ersetze die gelben Lücken [???] durch die passenden Befehle aus der Hilfe-Box!

from microbit import * while True: display.show(Image.[SYMBOL]) sleep([PAUSE_1]) display.clear() sleep([PAUSE_2])
💡 Hilfe-Box für die Lücken:
  • [SYMBOL]: z. B. HEART, HAPPY oder PACMAN
  • [PAUSE_1] & [PAUSE_2]: Zeit in Millisekunden (1000 = 1 Sekunde). Versuche z. B. 500.
🌟 Zusatz-Herausforderung: Schaffst du es, dass der micro:bit erst ein fröhliches Gesicht (HAPPY) anzeigt und danach ein trauriges (SAD)?

2. Projekt: Der Schrittzähler 🏃

Das Prinzip der Variablen:
Eine Variable ist wie eine beschriftete Box im Speicher des micro:bit. In unserer Box namens schritte speichern wir ab, wie oft der Bewegungssensor Erschütterungen misst.

🧩 Bauplan für deinen Schrittzähler

Tippe den Code selbst ab und fülle die Lücken aus:

from microbit import * # 1. Startwert festlegen schritte = 0 while True: # Zeige den aktuellen Stand an display.show([VARIABLE]) # Bei Schütteln: Zähler erhöhen if accelerometer.was_gesture('shake'): schritte = schritte + [ZAHL] sleep(200) # Reset bei Druck auf Knopf A if button_a.is_pressed(): schritte = [START_WERT]
💡 Denke nach:
  • Welche Variable speichert unsere Zahl? ([VARIABLE])
  • Um wie viel erhöht sich die Schrittzahl bei jedem Schütteln? ([ZAHL])
  • Auf welchen Wert schreibst du die Variable beim Zurücksetzen? ([START_WERT])
🌟 Zusatz-Herausforderung: Lass den micro:bit ein Stern-Symbol (Image.STAR) anzeigen, sobald du mehr als 10 Schritte geschafft hast!

3. Projekt: Türsensor 🚪

Bedingungen verstehen (Wenn ... Dann ... Sonst):
Der integrierte Kompass-Sensor misst Stärke von Magnetfeldern. Ein Magnet an der Tür hält den Wert hoch. Wird die Tür geöffnet, fällt die Stärke ab und der micro:bit schlägt Alarm!

🧩 Bauplan für die Alarmanlage

from microbit import * while True: # Magnetfeld messen magnet = compass.get_field_strength() # WENN Tür ZU ist (Magnet nah): if magnet > 50000: display.show(Image.[RUECKMELDUNG_OK]) # SONST (Tür AUF = ALARM!): else: display.show(Image.[ALARM_SYMBOL]) sleep(100) display.clear() sleep(100)
💡 Hilfe-Box:
  • [RUECKMELDUNG_OK]: Zum Beispiel YES
  • [ALARM_SYMBOL]: Zum Beispiel SKULL oder NO
⚙️ Wichtig vor dem Starten im Editor:
Stelle oben rechts im WebTigerPython-Editor den Modus unbedingt auf micro:bit (bzw. TigerJython micro:bit) um! Standardmäßig steht dort "Python 3" – dann erscheint sonst die Fehlermeldung "No module named microbit".

Arbeitsbereich: WebTigerPython
