1. Wie denkt der micro:bit?

Ein Programm ist wie ein Kochrezept: Der Computer arbeitet deine Anweisungen Zeile für Zeile von oben nach unten ab.

🔍 Klicke auf die Bauteile, um sie kennenzulernen:

Klicke oben auf ein Bauteil!

🧩 Aufgabe: Ergänze die Lücken selbst im Editor!

Tippe den folgenden Code rechts in den Editor ein. Ersetze die gelben Lücken [???] durch die passenden Befehle aus der Hilfe-Box!

from microbit import * while True: display.show(Image.[SYMBOL]) sleep([PAUSE_1]) display.clear() sleep([PAUSE_2])
💡 Hilfe-Box für die Lücken:
  • [SYMBOL]: z. B. HEART, HAPPY oder PACMAN
  • [PAUSE_1] & [PAUSE_2]: Zeit in Millisekunden (1000 = 1 Sekunde). Probieren z. B. 500.
🌟 Zusatz-Herausforderung: Schaffst du es, dass der micro:bit erst ein fröhliches Gesicht Image.HAPPY zeigt und danach ein trauriges Image.SAD?

2. Projekt: Der Schrittzähler 🏃

Das neue Konzept: Variablen!
Eine Variable ist wie eine kleine Box mit einem Namen, in der der micro:bit eine Zahl speichert. Wir nennen unsere Box schritte.

🧩 Bauplan für deinen Schrittzähler

Tippe den Code selbst ab und fülle die Lücken aus:

from microbit import * # 1. Erstelle die Box "schritte" und starte bei 0 schritte = 0 while True: # Zeige den aktuellen Stand an display.show([VARIABLE]) # Wenn der Sensor Erschütterung misst: if accelerometer.was_gesture('shake'): schritte = schritte + [ZAHL] sleep(200) # Reset bei Druck auf Knopf A if button_a.is_pressed(): schritte = [START_WERT]
💡 Denke nach:
  • Welcher Variablen-Name gehört in [VARIABLE]?
  • Um wie viel soll die Variable steigen, wenn geschüttelt wird? ([ZAHL])
  • Welchen Wert muss [START_WERT] beim Zurücksetzen bekommen?
🌟 Zusatz-Herausforderung: Erweitere den Code so, dass Knopf B ein Belohnungs-Symbol (z. B. ein Stern Image.STAR) anzeigt, wenn du mehr als 10 Schritte geschafft hast!

3. Projekt: Türsensor & Alarmanlage 🚪

Bedingungen verstehen (Wenn ... Dann ... Sonst):
Der Kompass-Sensor misst die Magnetstärke. Ist ein Magnet nah, bleibt der Wert hoch. Entfernt man den Magneten (Tür geht auf), fällt der Wert ab.

🧩 Bauplan für die Alarmanlage

from microbit import * while True: # Misst das Magnetfeld magnet = compass.get_field_strength() # WENN Magnet nah ist (Tür ZU) if magnet > 50000: display.show(Image.[RUCHMELDUNG_OK]) # SONST (Tür AUF = ALARM) else: display.show(Image.[ALARM_SYMBOL]) sleep(100) display.clear() sleep(100)
💡 Denke nach:
  • Welches Symbol passt für eine geschlossene Tür? (z.B. YES)
  • Welches Symbol schreckt Einbrecher ab? (z.B. SKULL oder NO)
🌟 Zusatz-Herausforderung: Baut im Klassenzimmer mit Krokodilklemmen und Alufolie einen echten Kontaktschalter für eure Schultasche!

Arbeitsbereich: WebTigerPython

✍️ Tippe den Code hier ein. Achte genau auf Groß- und Kleinschreibung!
