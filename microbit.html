1. Was ist der micro:bit?

Der BBC micro:bit ist ein kleiner Minicomputer. Mit Python-Befehlen sagst du ihm Schritt für Schritt, was er tun soll!

Hardware-Detektiv: Wo sind die Bauteile?

Nimm deinen echten micro:bit in die Hand und suche die Teile auf der Platine:

Klicke oben auf einen Knopf, um zu erfahren, wo du das Bauteil auf deinem echten micro:bit findest!

Aufgabe: Das blinkende Herz programmieren

Lies die Erklärungen hinter den Rauten (#). Sie zeigen dir genau, was jede Zeile bewirkt!

# Schritt 1: Lade alle Werkzeuge für den micro:bit from microbit import * # Schritt 2: Starte eine Endlosschleife (läuft ewig weiter) while True: # Zeige das Bild eines Herzens auf den LED-Lampen display.show(Image.HEART) # Warte eine halbe Sekunde (500 Millisekunden) sleep(500) # Schalte alle Lichter aus display.clear() # Warte wieder eine halbe Sekunde, bevor die Schleife von vorne beginnt sleep(500)

2. Projekt: Der Schrittzähler

Das Prinzip der Variablen: Eine Variable ist wie eine kleine Schachtel mit Namensschild im Speicher. Wir nennen unsere Schachtel schritte.

Code-Anleitung mit Erklärungen

# Schritt 1: Werkzeuge laden from microbit import * # Schritt 2: Stelle eine Schachtel bereit und lege zu Beginn die Zahl 0 hinein schritte = 0 # Schritt 3: Hauptschleife starten while True: # Zeige den aktuellen Wert aus der Schachtel auf den Lampen an display.show(schritte) # Prüfe: Wurde der micro:bit geschüttelt? if accelerometer.was_gesture('shake'): # Nimm die alte Zahl, rechne +1 dazu und lege sie wieder in die Schachtel schritte = schritte + 1 # Kurze Pause, damit ein Schütteln nicht doppelt gezählt wird sleep(200) # Prüfe: Wurde Taste A gedrückt? if button_a.is_pressed(): # Setze die Schachtel wieder auf 0 zurück schritte = 0
Erfinder-Challenge: Bau eine Ziel-Belohnung ein! Wenn schritte == 10 erreicht sind, soll ein Smiley erscheinen!
Prototyping / Bastelauftrag:
Befestige den micro:bit mit einem Klettband oder Gummiband sicher an deinem Schuh. Teste deinen Schrittzähler auf einer kurzen Strecke!

3. Projekt: Der Alarmanlagen-Türsensor

Bedingungen verstehen: Wir nutzen den Kompass als Magnet-Sensor. Wenn ein Magnet nahe am micro:bit ist, misst er ein starkes Magnetfeld. Entfernt man den Magneten, schlägt er Alarm!

Code-Anleitung mit Erklärungen

# Schritt 1: Werkzeuge laden from microbit import * # Schritt 2: Hauptschleife starten while True: # Miss die Stärke des Magnetfelds in deiner Umgebung magnet = compass.get_field_strength() # Wenn die Magnetstärke größer als 50'000 ist (Magnet ist nah an der Tür) if magnet > 50000: # Tür ist ZU -> Zeige ein grünes Häkchen display.show(Image.YES) else: # Sonst (Magnet ist weg!) -> ALARM! Zeige einen Totenkopf und blinke display.show(Image.SKULL) sleep(100) display.clear() sleep(100)
Prototyping / Bastelauftrag:
Klebe einen Schulmagneten an den Türrahmen und befestige den micro:bit an der Tür. Richte den Sensor so aus, dass er im geschlossenen Zustand das Häkchen zeigt!

4. Projekt: Das digitale Thermometer

Messdaten verarbeiten: Der micro:bit kann messen, wie warm es im Raum ist.

Code-Anleitung mit Erklärungen

# Schritt 1: Werkzeuge laden from microbit import * # Schritt 2: Hauptschleife starten while True: # Miss die aktuelle Temperatur und speichere sie in der Variable 'grad' grad = temperature() # Wenn Taste A gedrückt wird: Scroll die genaue Gradzahl als Text durch if button_a.is_pressed(): display.scroll(grad) # Wenn es kälter als 20 Grad ist: Zeige ein trauriges Gesicht if grad < 20: display.show(Image.SAD) else: # Wenn es 20 Grad oder wärmer ist: Zeige ein lachendes Gesicht display.show(Image.HAPPY)

5. Projekt: Der Musik-Synthesizer

Töne & Bewegung verbinden: Mit dem Befehl music.pitch() können wir Töne in genau festgelegten Frequenzen abspielen.

Code-Anleitung mit Erklärungen

# Schritt 1: Lade die Standard-Werkzeuge UND das Musik-Modul from microbit import * import music # Schritt 2: Hauptschleife starten while True: # Wenn Taste A gedrückt wird: Spiele eine kurze Fanfare if button_a.is_pressed(): music.play(music.BA_DING) # Wenn der micro:bit geschüttelt wird: Spiele einen Ton mit 440 Hertz für 200 Millisekunden if accelerometer.was_gesture('shake'): music.pitch(440, 200) # Wenn Taste B gedrückt wird: Stoppe sofort alle Töne if button_b.is_pressed(): music.stop()
Prototyping / Bastelauftrag:
Baue aus Karton eine Papier-Gitarre. Klebe den micro:bit an den Hals der Gitarre und erzeuge Töne durch Bewegen des Instruments!

6. Die Erfinder-Challenge: Sichere den Schatz!

Deine Meisterprüfung: Kombiniere Variablen, Sensoren, Bedingungen und Sound zu einer eigenen Alarmanlage für deine Schatztruhe oder deinen Rucksack!

Deine Bau-Kriterien:

  • Schärfen der Anlage mit Taste A.
  • Alarm auslösen beim Bewegen ODER beim Licht-Einfall.
  • Optischer und akustischer Alarm (Blinken & Sound).
  • Entschärfen mit einer Geheim-Kombination (Taste B).
Wichtige Python-Befehle im Überblick
display.show(Image.HEART) – Zeigt ein vorgefertigtes Bild an.
display.scroll("Text") – Lässt einen Text von rechts nach links durchlaufen.
sleep(1000) – Pausiert das Programm für 1000 Millisekunden (1 Sekunde).
button_a.is_pressed() – Prüft, ob Taste A im Moment gedrückt wird.
accelerometer.was_gesture('shake') – Prüft, ob das Board geschüttelt wurde.
temperature() – Gibt die aktuelle Temperatur als Zahl zurück.
